# Automated Sentiment-Driven Stock Market Analysis and Prediction System

## Project Overview
This project analyzes the relationship between public sentiment (news and media) and stock market performance. 
The system collects news headlines, performs sentiment analysis using Natural Language Processing (NLP), 
and correlates the sentiment scores with stock price movements. The system also uses a Linear Regression model 
to predict stock price changes based on sentiment scores.

The final results are visualized using a Power BI dashboard and deployed on a web page.

---

## Objectives
- To collect stock market data using financial APIs.
- To collect public sentiment data from news sources.
- To perform sentiment analysis using VADER NLP.
- To align sentiment data with stock price data using time-series analysis.
- To calculate correlation between sentiment and stock price.
- To build a prediction model using Linear Regression.
- To visualize insights using Power BI dashboard.
- To deploy the dashboard on a web page.

---

## System Architecture
News Data → Sentiment Analysis → Stock Data → Time-Series Alignment → Correlation → Prediction → Database → Power BI → Web Dashboard
